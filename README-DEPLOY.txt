AIRVISTA Flight Academy — Animated Catalog Preview

Open index.html for a local preview.

To publish safely without changing other websites:
1. Create a new PUBLIC repository on your GitHub account, e.g. airvista-catalog-preview (no README).
2. Upload ALL contents of this folder to the repository root: index.html, assets/ (all 17 images), and .nojekyll.
3. Settings > Pages > Deploy from a branch > main > / (root) > Save.
4. Wait for Pages to show an actual live URL, then test it on mobile.
5. Generate QR from the VERIFIED live URL only (not from the GitHub repository URL).

Preview purposes: claims of EASA approvals, partners, and aircraft ownership/availability must be verified by the client prior to public marketing. Illustrations and third-party aircraft images should not imply ownership.
